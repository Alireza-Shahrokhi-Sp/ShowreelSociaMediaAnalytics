## SLIDE 7: Task 3 – Post Engagement Regression (Post-Level) — The Honest Failure

**Visual Setup**:
- Large R² values prominently displayed (all negative)
- Single large statement explaining what this means
- Visual: perhaps a "failure" aesthetic (inverse colors, simple line)

**Content**:

**HEADLINE**:
```
Does post format predict engagement?

R² VALUES (all 5-fold CV means):
Mean Sentiment Score:    R² = -0.03
Controversy:             R² = -0.05
Total Interactions:      R² = -0.08
Reach:                   R² = -1.11

Result: ALL MODELS FAIL
```

**CENTRAL STATEMENT**:
```
NEGATIVE R² MEANS: The model performs WORSE than simply 
predicting the mean for every post.

This is not a modeling failure. It's a DATA FINDING: 
Post metadata (content form, music source, hashtags, posting hour) 
have ZERO predictive power for engagement metrics.
```

**DETAILED ANALYSIS**:
```
WHAT IT ASKED:
We had 1,493 posts with rich metadata: content form (carousel, reel, IGTV), 
music source, hashtag count, paid partnership status, posting hour/day, 
location, video duration, creator mentions. Can these features predict:
  a) How positive/controversial the audience vibe is (mean sentiment)?
  b) Total engagement (interactions)?
  c) Reach (estimated audience size)?

We expected format to matter—reels get more reach, videos drive engagement, etc.

WHAT WE FOUND:
Nothing works. R² < 0 across all targets. The baseline (always predict the 
post-level mean sentiment/engagement) outperforms every feature-based model.

WHY THIS HAPPENS (Root Cause Analysis):
1. WRONG FEATURE SET
   Engagement is driven by: Audience size, creator reputation, timing 
   (when followers are online), competitive context (other posts at that time).
   Post format is downstream of these. A viral creator's low-effort post 
   gets more reach than an unknown creator's polished post.

2. SMALL N + HIGH DIMENSIONALITY
   1,493 posts, 20+ metadata features → overfitting trap. Ridge regression 
   with CV helps, but the signal-to-noise ratio is fundamentally too low.

3. UNMEASURED CONFOUNDING
   Post popularity depends on audience, not just format. 
   We can't control for "how many followers saw this," "timing vs audience 
   timezone," "competing posts," etc.

4. MISSING CORE PREDICTORS
   We should predict engagement from: creator's follower count, their 
   historical engagement rate, audience timezone alignment, time of posting 
   relative to audience activity, number of competing posts at that time.

WHAT THIS TEACHES:
This is an instructive non-result. It tells us: FORMAT ALONE IS INSUFFICIENT 
FOR PREDICTING ENGAGEMENT. Strategy must account for audience size, 
creator reputation, and timing—not just post format.

HONEST CAVEAT:
This isn't a failure to fit a model; it's a failure to predict based on 
available features. If we added audience metadata (follower count, history), 
the model might succeed. But as-is, format is noise.
```

**Visual Callout Box**:
```
📊 METHODOLOGICAL INSIGHT
Negative R² is a feature, not a bug. It tells us something real about 
the data: Observable post features don't drive engagement. Reach is 
determined by audience size and timing, not format.
```

**DETAILED ANALYSIS**:
```

WHAT WE FOUND:
Clear spectrum. THE_EMOJI_REACTOR is 95% positive; THE_HATER is only 48%

INTERPRETATION BY PERSONA:

THE_EMOJI_REACTOR (95% positive):
- High emoji use, long comments, rapid engagement
- Naturally enthusiastic; sentiment and behavior align

THE_SUPERFAN (91% positive):
- High reply ratio, long tenure, loyal comments
- Committed fan base; naturally supportive

THE_SUPPORTER (87% positive):
- Reply ratio + word count; supportive engagement
- Community-oriented; positive tone

THE_RECOMMENDER (80% positive):
- Moderate across metrics; diverse engagement style
- Generally positive but less extreme

THE_CRITIC (62% positive):
- Lower positivity but still majority positive
- Engages with nuance; willing to praise AND critique
- Natural analytical approach

- Plurality negative (25%), not majority
- But still nearly half positive—more "provocateur" than pure negative
- Challenges through engagement, not avoidance
```

## SLIDE 12: Methodological Caveats – What to Trust & What to Question

**Visual Setup**:
- Two-column: "Caveats" left (red/warning tone), "Mitigations" right (green/confidence tone)
- Icons or visual markers for severity

**Content**:

**HEADLINE**:
```
Honest Limitations: What Constrains These Models
```

**LEFT COLUMN – CAVEATS** (warning color #A23B72):
```
⚠️ SENTIMENT CLASS IMBALANCE
81% positive, 14% neutral, 5% negative.
Baseline: "Always predict positive" = 81% accuracy (useless).
Risk: Model learns to guess positive; rare negatives ignored.

⚠️ SAMPLE BIAS (Task 1–4 data)
B (sentiment_instagram) = 487k of 499k comments.
Selection: Prioritized media-bearing posts.
Risk: Not uniform random. Rates ≠ population estimates.

⚠️ SMALL POST N (Task 3)
1,493 posts with 20+ features.
Risk: Overfitting, multicollinearity, unstable coefficients.
Result: Task 3 R² < 0 (honest failure, but expected).

⚠️ LEAKAGE RISK (if not careful)
Sentiment, emotion, intent are sibling LLM outputs.
Risk: If you use intent to predict sentiment, you're predicting
a label from its near-duplicate.
Mitigation: Task 2 uses only behavioral features (no LLM siblings).

⚠️ PERSONA LABELS ARE LLM-DERIVED
Task 1 "predicts" persona from behavior, but persona was 
assigned by LLM. Not ground truth; circular validation.
Risk: Model validates LLM, not external reality.

⚠️ OBSERVATIONAL, NOT CAUSAL (Mickey Models)
Beta-Binomial models show correlation, not causation.
Risk: Can't say "creator mentions cause progression."
Only: "Creator mentions associate with higher progression."
Confounding: Creators mention popular users more often.
```

**RIGHT COLUMN – MITIGATIONS** (confidence color #2E86AB):
```
✅ ALWAYS USE MACRO-F1, NOT ACCURACY
Macro-F1 = average F1 across all classes.
Treats rare classes fairly.
Task 2: 0.47 macro-F1 (accounts for imbalance).
Accuracy would be >80% (misleading).

✅ STRATIFIED CV & CLASS WEIGHTS
Every task uses stratified 5-fold CV.
Class-weighted balancing for imbalance.
Ridge regression regularization for small N.
Reduces overfit; stabilizes estimates.

✅ VALIDATE ON HOLDOUT SET
All tasks: Train on 80%, validate on 20% (unseen data).
CV variance reported: std < 0.005 for Tasks 1–2 (tight).
Low variance = generalizes well.

✅ PREVENT LEAKAGE IN TASK 2
Task 2 uses ONLY behavioral features:
- Text: word_count, emoji, punctuation
- Author: persona_codename (behavioral, not sentiment-derived)
- Post: content_form, posting time (metadata, not sentiment)
NO sentiment labels, emotion, intent as features.
→ Clean validation.

✅ INTERPRET TASK 1 AS "LLM VALIDATION"
Frame: "Do behavioral patterns align with LLM persona?"
Answer: Yes, 4.6× random. Persona taxonomy is coherent.
Not claiming personas are ground truth, but they're consistent.

✅ ACKNOWLEDGE TASK 3 AS DATA FINDING
R² < 0 is not failure; it's insight: Format alone insufficient.
Honest about limitations. Informs strategy (need audience data).

✅ MICKEY MODELS AS EXPLORATORY
Use patterns for strategy, not precise prediction.
Small N, rare events, observational data.
Caveats documented in posterior diagnostics.
```
